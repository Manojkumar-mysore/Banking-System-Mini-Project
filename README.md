🏦 Banking System Mini Project (Python)

A simple Python-based banking system built using Object-Oriented Programming (OOP). The project simulates basic banking operations using Savings and Current Account types.

🚀 Features

- Create a Savings Account or Current Account
- Deposit money into an account
- Withdraw money with balance validation
- Check the current account balance
- Display account details
- Support an overdraft limit of ₹1,000 for Current Accounts

🧠 Concepts Used

- Classes and objects
- Inheritance
- Encapsulation
- Conditional statements and program logic
- Account balance validation

🛠️ Technologies Used

- Language: Python 3
- IDE: PyCharm

⚙️ How It Works

1. Create an account.
2. Choose between a Savings Account and a Current Account.
3. Perform banking operations such as depositing, withdrawing, and checking the balance.
4. Current Account holders can use the ₹1,000 overdraft limit when the program's conditions allow it.

▶️ How to Run

1. Download or clone this repository.
2. Open the project in PyCharm or another Python editor.
3. Ensure Python 3 is installed.
4. Run the main Python file.

Note: Use the actual filename of your main Python script when running the project.
